# Parth Khandelwal — Portfolio

A modern, dark-themed personal portfolio website built to showcase my journey as a **B.Tech CSE (AI & ML) student**, my projects, technical skills, certifications, and creative work.

The portfolio is designed with a clean and minimal interface while keeping the focus on my development journey, projects, and continuous learning.

## 📌 About the Project

This portfolio is my personal space on the web where I showcase who I am, what I'm learning, and what I'm building.

I'm currently pursuing **B.Tech in Computer Science & Engineering (Artificial Intelligence & Machine Learning)** at **GLA University, Mathura**.

The website represents my transition from learning programming fundamentals to building practical projects in Python, web development, and eventually AI/ML.

Rather than being just a collection of projects, the portfolio also highlights my educational journey, certifications, interests, and creative side.
